# Java Practice

This Java project is a small Spring Boot exercise focused on building a simple message API with a MySQL-backed repository.

## Current project

- `pom.xml` - Maven setup for a Spring Boot application
- `src/main/java/com/codinglab` - Java source files for the app, controller, and repository

## Included behavior

- REST endpoints for listing, creating, updating, and deleting message records
- CLI commands for quick local testing
- MySQL table creation via JDBC schema initialization

## Notes

This is a real project and should stay structured as a standalone Java exercise instead of being treated as scratch material.
