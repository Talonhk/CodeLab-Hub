# Go Practice

This folder is for small Go learning exercises and quick syntax experiments.

## Current contents

- `main.go` - a simple introductory Go program demonstrating basic printing and formatting

## Notes

Keep the files here focused on learning and small, self-contained examples. If a script grows into a larger project, it should be moved into a more descriptive subfolder with its own README.

## Start workspace and services

```powershell
.\start.ps1
```

This ensures Kubernetes coding-lab services are running, then opens the Go container workspace.
