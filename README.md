# CodeLab Hub

This repository is organized as a learning and experimentation hub for coding, DevOps, infrastructure, and MLOps work.

## Project structure

- practice/
  - language and coding exercises
  - algorithm and scripting practice
  - small challenge projects

- devops/
  - Kubernetes, CI/CD, Terraform, and lab automation work
  - cluster and environment experiments

- mlops/
  - MLflow, deployment, model tracking, Docker, and inference workflows

- apps/
  - small application projects and app prototypes

- archives/
  - legacy or transitional work that should be reviewed before deletion

## Important note

The forked Terraform project at learning-terraform remains separate from this repository and is intentionally not merged into the main hub structure.

## Purpose

CodeLab Hub brings together the local projects that belong under one learning-focused umbrella while keeping independent forked work separate and easy to manage.
