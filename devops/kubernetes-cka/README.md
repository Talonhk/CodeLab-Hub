# Kubernetes CKA

Lab materials and practice exercises for Certified Kubernetes Administrator (CKA) exam preparation.

## Contents

A collection of Kubernetes manifests demonstrating various concepts:

- Pod configurations with resource limits and requests
- ConfigMap and Secret examples
- Deployment and ReplicaSet patterns
- Namespaces and quota management
- Volume and PVC configurations
- Network policies and service examples
- Init containers and multi-container pods

## Files

- YAML configuration examples for various K8s objects
- `Kubernetes-CKA.code-workspace` - VS Code workspace configuration
